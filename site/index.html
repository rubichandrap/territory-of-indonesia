Territory of Indonesia

Administrative boundaries of Indonesia as GeoJSON, from provinces down to villages, built from OpenStreetMap. This site serves the newest release of the index and simplified tiers. The files are served with CORS enabled, so a web page can fetch them directly.

Start here

  • v2/index/provinces.json: the provinces, without geometry. Each entry's children says which files exist below it.
  • v2/simplified/provinces.geojson: the provinces with simplified geometry, for drawing maps.
  • v2/manifest.json: what this release contains and exactly which OpenStreetMap files it came from.
  • v2/report.json: what looked wrong in OpenStreetMap while building it.

Layout

v2/index/provinces.json                    geometry-free entries
v2/index/regencies/<province id>.json
v2/index/districts/<regency id>.json
v2/index/villages/<district id>.json
v2/simplified/provinces.geojson            the same files with simplified geometry
v2/simplified/regencies/<province id>.geojson
...

Example

const base = "https://rubichandrap.github.io/territory-of-indonesia/v2";
const provinces = await (await fetch(`${base}/index/provinces.json`)).json();
const jabar = provinces.find((p) => p.name === "Jawa Barat");
const regencies = await (await fetch(`${base}/index/regencies/${jabar.osm_id}.json`)).json();

Good to know

  • This is always the newest release, so a file can change under the same URL. To pin a version, download a zip from the Releases page, which also has the full-resolution tier.
  • The v2 in the path is the format version, not a date. A future incompatible format would get a new path.
  • Coverage below the regency level is partial. report.json and the README say exactly what is and is not there.
